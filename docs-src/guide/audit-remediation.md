# 审计修复兼容说明

本页说明 2026 年 9 月审计修复的行为变化，供部署者和插件作者升级前核对。这些修改不改变数据库、TOML、插件 manifest 或认证存储的 schema，不需要手工迁移私有数据。已有显式配置值保留；新缺省值只影响未配置字段。

## 部署与恢复

- 服务管理器或容器注入的环境变量优先于项目 `.env`，包括显式空值。缺少 `HOST`、`PORT` 时使用 `127.0.0.1:8000`；非法端口会给出配置错误。跨容器连接方式见 [Docker 安装](docker-installation.md)。
- Worker 异常退出后，Runner 按 1、2、4 秒逐步退避，最多 60 秒重启；连续稳定运行 60 秒后重置退避。正常退出与终止信号不会按崩溃自动重启，42/43 的受控重启、更新语义保留。
- Worker 初始化、调度失败与受控退出都会进入清理。周期任务的单轮异常不再永久终止任务，下一周期重试；一次性任务错误仍会传播。
- 消息库和记忆库使用 WAL + `synchronous=NORMAL`，降低 `OFF` 带来的数据库损坏风险。NORMAL 不保证断电时保留最近已提交事务，也不能替代备份。
- 本地状态文件采用临时文件加原子替换，写失败不会报告内存状态已提交。无效 JSON 保留为 `local_store.json.corrupt.<随机编号>` 后重建；需要恢复时先检查备份内容。
- 配置/协议确认文件的新写入使用 0600。Plan/Reply 诊断仍保留管理员需要的完整内容，目录使用 0700、新文件使用 0600；此功能不提供加密。

## 配置与模型

- 供应商 `timeout` 缺省从 10 秒调整为 60 秒，已有显式数值不覆盖。平台账号缺省为空列表，已有账号保留。
- 配置对象转为字符串时遵守敏感字段的 `repr=False`；学习规则包含非字符串条目时给出校验错误。未知 TOML 字段和遗留 LPMM 配置继续兼容。
- 每流表达学习和黑话学习独立启用；只开启黑话学习也会被调度。
- 自定义流式回调遇到网络错误会终止当前请求，避免重试重复交付已输出内容。默认完整缓冲的调用继续使用原有重试策略。
- Gemini embedding 仅采用 SDK 返回的真实 token 统计，缺失时 `usage` 为空；不会再以字符数冒充 token 数。语音请求按实际格式设置 MIME，无法识别的格式在客户端边界拒绝。

## 聊天与插件

- 消息查询省略 `limit` 时最多返回 1000 条；原本已有较小默认上限的接口保持原值。显式 `limit=0` 仍表示不限制，导出应主动选择它或按时间窗口查询。`limit_mode` 与排序语义保持原契约，见 [消息 API](../plugins/api/message-api.md)。
- ChatManager 查询返回隔离的流元数据快照；修改返回对象不再隐式修改缓存。群聊、私聊和工具执行器会刷新当前快照。公开 `initialize()`、`auto_save()`，旧私有方法名保留兼容别名。
- `AFTER_SEND` 修改不会覆盖已发送正文的数据库记录。要改发送内容，应在发送前钩子中完成；事后钩子的原有取消行为保留。
- 私聊命令 `intercept_message_level=1` 按既有契约不触发回复，但仍可出现在后续回复上下文中。
- 插件重载会重新执行入口源码。其他模块持有的旧对象、插件自行启动的外部工作不能自动替换；这类插件更新后应重启进程。
- 表情替换先登记新图再移除旧图。新图注册失败保留旧图；旧图删除失败时允许暂时同时保留两条，以免数据净损失。文件、SQLite、向量服务之间不具备跨系统原子事务。

## WebUI

- 清空聊天历史只接受 WebUI 虚拟聊天室，真实群 ID 返回 400。
- 虚拟身份必须对应已存在且平台匹配的画像；昵称和账号来自画像，客户端不能覆盖它们。
- 导入任务取消/删除遇到后台状态变化时返回 409，刷新状态后再操作。
- 插件列表 GET 不再写回缺失的 manifest ID；列表仍返回兼容 ID。
- 登录限流与防爬共享可信代理链解析。只为实际受控的反向代理配置可信地址，代理应正确追加或重建转发头。
- WebSocket 的 CSP 连接范围收紧到当前请求源。外链 HTTPS 图片继续支持。

## 记忆与性能边界

SQLite 继续是数据源，Qdrant 是可选索引。远程 Qdrant I/O 移出事件循环，同时保持 profile、alias 与状态提交顺序；取消已开始的远程操作时，会先等操作完成再传播取消，避免旧写入晚于新删除。嵌入式本地模式保留原线程行为。

月度洞察与梦境软上限扫描只读取需要的元数据，正文仅按候选批次加载；计数仍覆盖全部符合条件的原子。内存开销仍随实体数和候选上限增长，不代表全部记忆操作都已变成常数内存或异步数据库访问。同步事务与兼容 API 继续保留，未更换存储引擎。
